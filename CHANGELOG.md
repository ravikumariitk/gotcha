# Changelog

All notable changes to this project are documented here.

## [0.1.0] - 2026-11-17

Initial public release.

- Signed, expiring motion CAPTCHA challenges
- MP4 rendering with PNG-frame fallback when `ffmpeg` is unavailable
- HMAC verification with replay protection
- Five-attempt challenge limit
- Appearance and texture configuration
- Runnable basic and login integration examples
